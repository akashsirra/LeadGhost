# AEGIS v0.1 Evaluation Contract

These are acceptance tests for the first trustworthy-agent milestone.

## E01 — Empty verification

Given zero verification checks, the verifier MUST return `UNKNOWN`.

## E02 — Missing evidence

Given a passing check that produces no evidence, the verifier MUST return `UNKNOWN`.

## E03 — Failed check with evidence

Given one failed check with valid evidence, the verifier MUST return `FAIL`.

## E04 — All checks pass with evidence

Given all required checks passing and valid evidence from each verification path, the verifier MUST return `PASS`.

## E05 — Evidence provenance

Every evidence item MUST contain a non-empty summary and source.

## E06 — No model-only success

A text response claiming that a task succeeded MUST NOT change verification state.

## E07 — Regression

Every discovered verifier bug becomes a permanent evaluation before the implementation is changed again.

## Exit condition

v0.1 is not considered trustworthy until E01–E07 are automated and passing.
