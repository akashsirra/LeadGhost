# AEGIS v0.1 Policy

## Default posture

- Read operations are preferred over mutation.
- Tool access must be explicit.
- Verification is required before a task can be marked successful.
- Destructive actions require a future approval layer; v0.1 does not expose them autonomously.
- Secrets must never be written into evidence or logs.
- External side effects are out of scope for the first runtime.

## Trust boundary

The model proposes actions. The runtime decides whether an action is permitted. The verifier decides whether the claimed outcome is supported.
