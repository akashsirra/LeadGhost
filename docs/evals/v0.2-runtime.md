# AEGIS v0.2 Runtime Evals

The runtime milestone is complete only when these behaviors are mechanically verified.

- **R01 — Plan:** every accepted task produces an explicit action plan.
- **R02 — Least privilege:** an action can execute only when its tool is registered.
- **R03 — Observation:** tool output is captured in the execution trace.
- **R04 — Evidence:** tool execution and verification create provenance-bearing evidence.
- **R05 — Verification:** every verification check must have evidence.
- **R06 — Unknown boundary:** missing evidence produces `UNKNOWN`, never `PASS`.
- **R07 — End-to-end:** a deterministic task can reach `PASS` through plan → execute → observe → verify → evidence.

The current planner is intentionally deterministic. It is a runtime harness, not a claim that a language model is already driving the system. A model can be attached later behind the `Planner` interface without changing the verifier contract.
